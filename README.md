# Cumulative Machine Learning and Digitalization Insights into Grinding Processes with Multi-Alloy and Multi-Cooling Variability


The grinding process is inherently complex and non homogeneous due to the simultaneous influence of multiple parameters, typically ranging from 8 to 15, which directly affect surface roughness and overall workpiece quality. This complexity is particularly critical in high precision industries such as aerospace and medical device manufacturing. Despite its industrial relevance, most existing studies have focused on single alloy implementations, leaving a gap in cumulative approaches that treat alloy type as a variable predictor alongside other process parameters.
This study addresses that gap by consolidating three distinct grinding datasets—Inconel 718, Steel ST34, and Aluminum—under diverse cooling conditions into a single universal dataset. A multi criteria decision making (MCDM) framework was introduced to harmonize 16 initial parameters, resulting in a consolidated dataset of 10 key predictors, including alloy type and coolant type as novel variables. Preprocessing and statistical analysis revealed the limitations of conventional methods such as N Way ANOVA, underscoring the need for advanced machine learning approaches.
Five machine learning models—Support Vector Regression (SVR), Gaussian Process Regression (GPR), Artificial Neural Networks (ANN), Ensemble methods, and k Nearest Neighbors (KNN)—were implemented with Bayesian hyperparameter tuning. Among them, the Ensemble model achieved the highest predictive accuracy (R^2=0.83, mean accuracy = 83% on testing), followed closely by GPR. SHAP based sensitivity analysis confirmed the dominant influence of specific removal rate, grinding wheel type, and dressing speed, while validating alloy type and coolant type as significant contributors.
Finally, a Green Machining Framework Application was developed, integrating the dataset, models, and sensitivity analysis into a user friendly platform. This tool enables parameter input, prediction, and interpretability, offering a scalable solution for multi alloy grinding optimization and advancing sustainable, intelligent manufacturing practices.
